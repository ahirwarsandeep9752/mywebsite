# ViralHook AI 🚀

ViralHook AI is a SaaS tool that generates viral content hooks using AI.

## Features
- AI powered hook generator
- Free + Pro system
- Daily usage limit
- Razorpay payment integration
- Admin dashboard
- Email notifications

## Tech Stack
- Flask
- Google Gemini AI
- Razorpay
- SQLite
- Gunicorn

## Run locally
```bash
pip install -r requirements.txt
python app.py
